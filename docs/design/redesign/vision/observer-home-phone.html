App bar. Three-slot grid (1fr auto 1fr), so the title is centred on the screen, not between the buttons. Menu keeps its word: observers read labels faster than icons.
Needs you. One card, one count, one action per row. It disappears when nothing waits, so the home page is calm most of the day.
Report rows. 88 px, one list, no card per row. Title, place and time, then status (shape plus word) beside the receipt code, so the code is never mistaken for a heading.
Bottom bar. 56 px plus the safe area. Active: a 56 by 32 sunk pill behind the icon and ink label. Report is always the ink pill: it opens the flow and is never "current".
Menu. Home, My reports and Messages left the menu: they live in the bottom bar now. Sign out is last, in danger red, away from the thumb's usual path.
