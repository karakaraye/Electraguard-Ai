Rules for every effect

Only transform and opacity are animated, so nothing reflows. Durations stay between 120 and 320 ms for interface feedback; only the send sequence (640 ms) and the queue highlight (1.6 s) are longer because they report a result. Nothing loops except the send ring while the network works. Reduced motion: when the system setting is on, or the switch at the top is on, every effect becomes an 80 ms opacity fade to its final state, with no movement and no vibration. Save Data turns off the art motion but keeps these interface fades.
