# How to Check Report Status

ElectraGuard AI dey make sure say every person wey send report get proof and fit check how dem dey handle am.

## Your Receipt Code
Any time you send report finish, the system dey give you one special receipt code (e dey look like `EG-····-····`: the letters EG, then two groups of four letters or numbers). Keep this code safe.

## How to Check for Mobile App
If you report through the smartphone web app:
1. Touch **My Reports** for menu.
2. Pick any report make you see the timeline:
   - **Received:** E don reach central server, e dey wait for line.
   - **In Review:** Reviewer dey look your report and picture now.
   - **Needs Clarification:** Reviewer don ask you question. Open am make you reply.
   - **Closed:** Dem don finish review and put final answer (Corroborated, Insufficient Evidence, or Out of Scope).

## How to Check with SMS or Basic Phone
If you report with USSD (`*384*24#`) or SMS:
- You go receive SMS with your receipt code.
- To check status anytime, send SMS with word `STATUS` and your receipt code (example: `STATUS EG-····-····`) go the short code.
- You fit also enter the receipt code for public website for `electraguard.ng/p`.

If your status no change or you miss your code, check with your coordinator.
