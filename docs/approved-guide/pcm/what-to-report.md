# Wetin You Suppose Report

When your report clear and straight, e dey help situation room understand wetin really dey happen on election day.

## Important Things to Report
1. **Late Opening and Missing Materials:** Write if the polling unit open late. Note if ballot paper, result sheet, ink, or officials never arrive.
2. **Machine Trouble:** Report if BVAS machine no gree on, no gree read thumbprint or face, or battery finish.
3. **Long Queue and Crowd:** Report if the line long too much, if sun dey beat people without shade or water, and if voters dey tire dey go house.
4. **Wahala and Threat:** Report any fighting, shouting, weapon, or person wey dey try scatter the voting.
5. **Wetin Dey Block People to Vote:** Note if old people, pregnant women, or people living with disability no fit enter because of stairs or long distance.
6. **Vote Buying:** Report if anybody dey share money, food, or gift to buy vote near the polling unit.
7. **Good Behavior:** Also report good things! Write if officials come early, treat old people well, and count vote with open eye.

## How to Write Correct Report
- Write only wetin you see and hear with your own eye and ear.
- Put the exact time.
- Write facts plainly without guessing wetin dey mind person.
- If you no sure which category fit your report well, pick the one wey close pass and check with your coordinator.
