# What to Report

Clear and accurate field reports help the central situation room understand the real situation on polling day.

## Key Events to Record
1. **Opening Delays & Missing Materials:** Record if the polling unit opens late. Note if sensitive materials (ballot papers, result sheets, ink pads, stamps) or polling officials are missing.
2. **Equipment Issues:** Note if biometric voter accreditation devices (BVAS) fail to power on, fail to read fingerprints or faces, or run out of battery.
3. **Queues and Crowding:** Report if the queue is exceptionally long, if there is no shade or water in extreme heat, or if voters give up and leave.
4. **Intimidation and Violence:** Document any threats, shouting, physical fights, weapons, or attempts to disrupt the voting process.
5. **Accessibility Barriers:** Note if elderly persons, pregnant women, nursing mothers, or voters with disabilities face obstacles like stairs without ramps or long walking distances.
6. **Vote Buying and Bribery:** Report any offering of cash, food, or gifts in exchange for votes near the polling unit.
7. **Good Practices:** Also report positive conduct! Note if officials arrive on time, assist elderly voters kindly, and count ballots transparently.

## Writing a Good Report
- Stick to what you saw and heard directly.
- Note the exact time.
- State facts plainly rather than guessing motives.
- If you are not sure which category best fits an incident, choose the closest option and check with your coordinator.
