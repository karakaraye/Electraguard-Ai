# How to Check Report Status

ElectraGuard AI ensures that every reporter receives a clear record of their submission and can monitor how it is being processed.

## Your Receipt Code
Whenever you successfully send an incident report, the system issues a unique, tamper-proof receipt code (it looks like `EG-····-····`: the letters EG, then two groups of four letters or numbers). Keep a record of this code.

## Checking Status in the Mobile App
If you submitted through the smartphone web app:
1. Tap **My Reports** in the main navigation.
2. Select any report from your list to view its current timeline:
   - **Received:** The report has reached the central server and is waiting in the review queue.
   - **In Review:** An analyst is actively examining your report and evidence.
   - **Needs Clarification:** The reviewer has sent you a question. Open the case to type your reply.
   - **Closed:** The review is complete, and the outcome has been recorded (Corroborated, Insufficient Evidence, or Out of Scope).

## Checking Status by SMS or Feature Phone
If you reported using basic USSD (`*384*24#`) or SMS:
- You will receive an SMS containing your receipt code.
- To check status at any time, send a text message with the word `STATUS` followed by your receipt code (example: `STATUS EG-····-····`) to the official short code.
- You can also enter your receipt code on the public web portal at `electraguard.ng/p`.

If your report status is not updating or you lose your receipt code, check with your coordinator.
